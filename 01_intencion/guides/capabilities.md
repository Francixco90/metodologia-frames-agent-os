# Qué puede hacer Frames

Frames coordina trabajos de contenido, multimedia y carrera profesional alrededor de una regla simple: primero entender el resultado, después producir. No necesitas conocer el nombre del proceso interno; el sistema selecciona el recorrido a partir de tu pedido y muestra sus límites.

## Qué puede hacer Frames

### Contenido y comunicación

- Crear un brief para una pieza, serie, campaña o intervención.
- Definir audiencia, acción esperada, mensaje, tono y canales.
- Diseñar conceptos A/B, narrativa, continuidad y mapa de activos.
- Preparar parrillas, calendarios, charters, cronogramas y dependencias.
- Crear prompts gobernados para imágenes, gráficas, carruseles, historias y miniclips.
- Revisar marca, evidencia, derechos, accesibilidad y consistencia.
- Editar una versión candidata sin perder la anterior.

### Presentaciones y decisiones ejecutivas

Frames puede convertir una fuente compleja en un acuerdo de presentación, una historia ejecutiva con la conclusión primero, una secuencia de diapositivas, notas visuales y criterios de aceptación. Si el entorno no tiene un generador de presentaciones registrado, se detiene en la especificación o borrador HTML en lugar de afirmar que creó un PPTX.

### Carrera profesional

- Construir un banco de evidencia profesional y detectar contradicciones.
- Crear un CV general o adaptado a una vacante en Markdown y HTML.
- Preparar un PDF ATS cuando el generador local y la extracción de texto estén acreditados.
- Escribir cartas, respuestas de formulario y mensajes breves sin duplicar el CV.
- Buscar y puntuar oportunidades desde snapshots autorizados.
- Preparar una postulación y detenerse antes del envío.

## Niveles de capacidad

| Nivel         | Significa                                                                          | Ejemplo                                                    |
| ------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| Disponible    | Frames puede producir y verificar el output local                                  | brief Markdown/HTML, matrices, planes, CV HTML             |
| Asistido      | Frames hace la parte metodológica y deja una acción humana o herramienta pendiente | presentación ejecutiva sin generador PPTX, revisión visual |
| Preparado     | El paquete está listo, pero el efecto externo sigue bloqueado                      | distribución P09 o postulación C09                         |
| No habilitado | Falta autoridad, licencia, toolchain o conector                                    | publicación automática, CAPTCHA, mensajes masivos          |

## Qué entrega cada recorrido

| Recorrido        | Entregables frecuentes                                                         | Punto de parada                                  |
| ---------------- | ------------------------------------------------------------------------------ | ------------------------------------------------ |
| Pieza nueva      | brief, conceptos, creative spec, asset map, prompts, revisión                  | aprobación humana antes de producir o distribuir |
| Campaña          | campaign charter, cronograma, content grid, hitos, medición                    | aprobación del brief y del plan                  |
| Presentación     | acuerdo ejecutivo, historia, mapa de diapositivas, mensajes y dirección visual | generador final si no está acreditado            |
| CV               | foundation brief, evidence bank, CV Markdown/HTML, QA ATS                      | envío a una vacante                              |
| Carta            | requirement–evidence map, carta, mensaje o respuesta                           | aprobación del paquete                           |
| Búsqueda laboral | search brief, queries, inventario, scorecards, shortlist                       | contacto o postulación externa                   |

## Qué no promete

- No convierte un template en prueba de que algo fue ejecutado.
- No atribuye una capacidad a una persona porque la vacante la solicite.
- No presenta estimaciones como métricas medidas.
- No garantiza que una plataforma acepte un documento sin probar el canal real.
- No usa marcas, rostros, voces o materiales sin autoridad y derechos suficientes.
- No publica ni envía solo porque el usuario pidió “hacerlo todo”. Cada efecto externo conserva una aprobación específica.

Cuando una capacidad no está disponible, Frames debe conservar lo ya producido, explicar el bloqueo y recomendar una reparación concreta.
