# Experience Release Vault

Este vault acepta únicamente cápsulas `APPROVED` de Frames Experience OS. Cada
cápsula debe conservar hashes materiales, compatibilidad, migración, restauración,
evidencia de aceptación y decisiones independientes de RT-09, RT-11 y H01.

Los candidates se construyen y verifican en directorios temporales. No se guardan
aquí timestamps, PII, secretos, contexto privado ni estado mutable. Un merge no
autoriza publicación, conectores ni efectos externos. [CONFIG]
