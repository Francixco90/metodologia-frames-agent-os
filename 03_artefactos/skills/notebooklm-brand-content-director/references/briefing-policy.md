# Brand content briefing policy

## Template selection

Select by intended consumption and final contract, not by the user's first format word. Use one
primary template. If the request needs multiple pieces, create one brief per piece and connect them
through a shared narrative ID; do not reuse one generic prompt across formats.

## Source roles

- Control: routing, safety and output contract.
- Canon: voice, audience, positioning and visual rules.
- Evidence: only sources that support the selected claims.
- Template: exactly the selected delivery contract.
- Golden reference: optional, maximum two, with imitation boundaries.
- Asset: only approved IDs needed for the piece.

Compute idempotency from normalized intent, template version, locale, profile digest and ordered
source-set digest. A repeated active request returns the existing artifact reference.

## Handoff acceptance

The brief names a measurable output, excludes internal instructions from visible content, declares
what must not be invented and provides checks a verifier can observe. Missing optional creativity
inputs may remain open; missing claims, rights or authority block the affected element.
