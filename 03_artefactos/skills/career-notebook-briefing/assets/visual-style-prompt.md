# MetodologIA Neo-Swiss Executive Debrief

Crear un documento ejecutivo para `{{owner_name}}`, coherente con
`{{brand_name}}` y la composición `neo-swiss-editorial`. Usar retícula suiza de
12 columnas, composición asimétrica ordenada, jerarquía fuerte, economía visual
y espacio negativo. Comunicar una idea, un dato verificable, una lectura y un
próximo movimiento por página.

Resolver la paleta desde `{{design_system_ref}}`: navy como canvas, superficies
tonales, texto claro y dorado como único acento. No usar semáforos verde/rojo,
cyan, púrpura, neón ni gradientes multicolor. Diferenciar estados con texto,
forma, borde e icono; nunca solo con color.

Usar Poppins 700–800 para titulares y cifras, Montserrat 500–700 para labels y
Trebuchet MS para cuerpo y notas. Si faltan, usar sans geométrica equivalente y
máximo tres familias. Usar iconografía lineal, sin emojis ni fotos de stock.

Formato 16:9. Mantener 30–45 palabras por slide, una visual dominante y máximo
cuatro bloques. Incluir unidad, alcance y periodo en cifras. No mostrar un
porcentaje sin denominador. Narrar `contexto → señal → lectura → decisión → gate`.
Separar hechos, inferencias y gaps; no inventar causalidad ni conversiones.
