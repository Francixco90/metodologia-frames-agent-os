# MetodologIA · Formación · Canon versionado v1

Este pack conserva las 21 versiones históricas de Masterclass y Playbooks y agrega, sin sobrescribirlas, 22 ediciones nuevas de Drive y 24 PDFs recuperados de Studio.

## Regla de autoridad

1. Un archivo maestro aprobado prevalece sobre cualquier proyección.
2. Las ediciones del Drive del programa se tratan como canon operativo nuevo.
3. Las versiones históricas permanecen disponibles como galería y referencia comparativa.
4. Los decks descargados de Studio son candidatos hasta completar revisión editorial, trazabilidad y derechos.

El título no determina identidad. Cada versión se identifica por `content_sha256`. Dos procedencias con el mismo hash representan un único contenido con dos receipts; dos archivos con el mismo título y hashes distintos se conservan como versiones diferentes.
