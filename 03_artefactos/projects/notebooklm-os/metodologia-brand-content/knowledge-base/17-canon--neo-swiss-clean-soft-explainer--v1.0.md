# Neo-Swiss Clean and Soft Explainer

Versión: `v1.0`
Nombre completo: `Neo-Swiss Clean and Soft Explainer (Corporate Clean and Premium)`
Propietario: `MetodologIA`
Estado: `ACTIVE_VISUAL_CANON`

Esta es la estética oficial declarada para el perfil Brand Content Studio. Prevalece sobre estilos observados, prompts históricos o inferencias visuales que entren en conflicto. [METODOLOGIA]

## Firma visual

Diseño editorial suizo, limpio y premium, suavizado mediante geometrías amables y explicaciones visuales accesibles. El fondo blanco funcional domina; el orden proviene del grid, las columnas y el espacio negativo. La ilustración vectorial flat es vibrante pero funcional: explica acciones, relaciones o decisiones. [METODOLOGIA]

## Paleta exclusiva

| Token              | Hex       | Rol principal                                      | Restricción                                   |
| ------------------ | --------- | -------------------------------------------------- | --------------------------------------------- |
| Navy institucional | `#122562` | ancla, títulos, bandas y estructura                | no convertir todo el lienzo en bloque oscuro  |
| Oro de decisión    | `#FFD700` | foco, verificación, selección o elemento activo    | nunca texto blanco sobre oro; uso escaso      |
| Azul técnico       | `#137DC5` | enlaces conceptuales, proceso, tecnología y apoyo  | no competir con el oro como foco              |
| Carbón             | `#1F2833` | texto principal y contraste                        | preferido sobre fondos claros                 |
| Lavanda            | `#BBA0CC` | suavidad, categorías secundarias y microgradientes | nunca reducir legibilidad                     |
| Gris               | `#808080` | metadatos, líneas y estados secundarios            | no usar para cuerpo crítico si baja contraste |

No se agregan colores externos. Variaciones de opacidad o microgradientes solo derivan de esta paleta. [METODOLOGIA]

## Tipografía

- `Poppins`: titulares, cifras decisivas y navegación principal.
- `Montserrat`: cuerpo, explicaciones, tablas y listas.
- `Trebuchet`: notas pequeñas, footnotes, popups, chips y callouts.

Jerarquía mínima: titular grande; cuerpo cómodo; metadatos claramente secundarios. Si una tipografía no está disponible, la salida debe declararlo y usar un fallback legible sin afirmar equivalencia exacta. [METODOLOGIA]

## Composición

- Grid suizo y orden editorial visible.
- Mucho espacio en blanco; evitar llenar cada región.
- Composición por columnas, con relación explícita `texto + visual`.
- Una idea central por pantalla, slide o unidad visual.
- Visual explicativo como contraparte del texto, no como fondo decorativo.
- Alineación, intervalos y radios consistentes.
- Numeración y navegación visibles en documentos secuenciales.

## Lenguaje de ilustración

- Vectorial flat, vibrante y no realista.
- Figuras humanas sin rostro únicamente cuando ayudan a explicar una acción o relación.
- Formas geométricas suaves, bordes limpios y proporciones simples.
- Sombras suaves y microgradientes discretos; nunca iluminación cinematográfica.
- Iconografía simple, coherente en trazo, peso y escala.
- Elementos UI permitidos: chips, checklists, timers, cards, tabs, badges y controles esquemáticos.

## Legibilidad y accesibilidad

- Texto grande y alto contraste.
- Nunca texto sobre fondos ruidosos, fotografías o ilustraciones complejas.
- El oro comunica estado o foco, no texto largo.
- No depender solo del color para indicar éxito, riesgo, selección o secuencia.
- Tablas y gráficos incluyen rótulos explícitos y lectura lógica.
- El contenido debe seguir siendo comprensible sin decoración ni animación.

## Uso de logo y fotografías

El logo se aplica desde el archivo maestro aprobado; no se genera, redibuja ni deforma. Las fotografías y retratos se insertan solo cuando `50-assets--manifest-and-usage--v1.0` declare el hash, estado y uso permitido. El estilo vectorial no autoriza convertir un retrato real en ilustración sin permiso. [METODOLOGIA]

## Adaptación por formato

| Formato         | Aplicación                                                                  |
| --------------- | --------------------------------------------------------------------------- |
| Deck            | retícula constante, 35–45% visual explicativo, numeración y footer discreto |
| Carrusel        | portada de alto contraste, progresión por tarjetas, un giro por lámina      |
| One-pager       | decisión arriba, columnas escaneables, evidencia y CTA separados            |
| Infografía      | jerarquía vertical, conectores claros, cifras con contexto y fuente         |
| Social estático | una tesis, un visual, una marca; no miniaturizar un deck                    |
| Reporte         | estructura editorial sobria; color reservado para navegación y decisión     |

## Red flags

Bloquea: 3D, ciberpunk, fotorealismo como estilo generado, fondos cinematográficos, glassmorphism excesivo, neón, ruido, texturas densas, decoración vacía, iconos mezclados, demasiados gradientes, texto sobre imagen, marcas externas o colores fuera de paleta. [METODOLOGIA]

## Checklist de aceptación

- ¿Se reconoce el fondo blanco, grid suizo y composición por columnas?
- ¿La paleta contiene exclusivamente los seis colores autorizados?
- ¿Oro significa foco o decisión?
- ¿Poppins/Montserrat/Trebuchet cumplen sus roles?
- ¿El visual explica y no decora?
- ¿La lectura es clara en tamaño de uso real?
- ¿Logo, foto o retrato tiene master, hash, derechos y uso aprobado?
