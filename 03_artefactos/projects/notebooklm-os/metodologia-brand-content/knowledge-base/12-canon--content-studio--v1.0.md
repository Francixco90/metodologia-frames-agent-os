# Canon de creación para Brand Content Studio

Versión: `v1.0`
Estado: `ACTIVE_INTERNAL`

## Principio rector

El contenido de MetodologIA convierte información en una experiencia que permite comprender, recordar, decidir o actuar. Lo visual no decora: organiza la atención y comunica valor. [METODOLOGIA]

## Ingeniería del asombro

El Factor WOW no se trata de exageración. Surge de cuatro componentes:

1. **Relevancia:** resolver una tensión real de la audiencia.
2. **Claridad:** eliminar fricción cognitiva y hacer visible la tesis.
3. **Estética funcional:** usar composición, contraste y metáfora para explicar.
4. **Sello humano:** criterio, tono, valores y curaduría que no se delegan.

El asombro sin relevancia es espectáculo; la claridad sin acción es información pasiva. [INFERENCIA]

## Arquitectura editorial

Antes de diseñar:

1. escribe la conclusión;
2. selecciona dos o tres soportes MECE;
3. identifica evidencia y gaps;
4. define la acción;
5. elige la metáfora visual;
6. adapta el contenido al canal.

Una unidad visual tiene una idea dominante. El titular expresa la conclusión; el cuerpo la sostiene; el visual agrega significado. [METODOLOGIA]

## Dirección artística

- Usa espacio negativo para crear jerarquía y reducir carga.
- Garantiza una lectura inicial en pocos segundos, sin convertir esa pauta en una métrica científica.
- El color destaca decisiones o información; no adorna indiscriminadamente.
- Define estética, composición, paleta, contraste, iluminación, proporción y exclusiones.
- Las restricciones visuales elevan consistencia y reducen resultados genéricos.
- Conserva coherencia entre texto, imagen, voz, audio e interacción.
- Mantén logos y retratos fuera de la generación; aplícalos exactamente en postproducción cuando estén aprobados.

## De párrafos a patrones

Transforma densidad en estructura:

- secuencia → timeline;
- comparación → tabla o dos columnas;
- sistema → diagrama de componentes;
- causalidad → flujo;
- jerarquía → árbol;
- progreso → etapas;
- evidencia cuantitativa → gráfica con fuente y unidad.

Si una visualización no mejora la comprensión, usa texto breve. [METODOLOGIA]

## Patrones por artefacto

### LinkedIn

Tensión reconocible → tesis → 2–3 soportes → ejemplo o evidencia → acción. Las dos primeras líneas deben funcionar sin contexto previo. [METODOLOGIA]

### One-pager

Audiencia → problema → tesis → método → prueba → límites → siguiente paso. Debe poder escanearse sin perder la conclusión. [METODOLOGIA]

### Deck corto

Contexto → tesis → sistema → prueba → decisión. Una idea por slide. La revisión crea una versión sucesora. [METODOLOGIA]

### Masterclass

Estado actual → tensión → costo → cambio de paradigma → marco → aplicación → práctica → criterios → cierre. [INFERENCIA]

### Playbook

Problema → principio → diagnóstico → método → rutina → prompt → ejemplo → señales → riesgos → acción. [INFERENCIA]

### Multimedia y formatos de Studio

Audio prioriza conversación y comprensión auditiva; video requiere guion y dirección de escena; infografía exige una relación visual central; reporte prioriza trazabilidad; flashcards y quiz evalúan objetivos distintos; tabla estructura comparaciones; mapa mental representa relaciones. Cada uno exige un brief propio. [METODOLOGIA]

## Criterios de aceptación

- Identidad escrita correctamente y sin mezcla de marcas.
- Tesis repetible en una frase.
- Claims fuertes sustentados o marcados como gaps.
- Estructura adecuada a audiencia y canal.
- Metáfora visual funcional y no copiada.
- Contraste, legibilidad y texto alternativo.
- Activos aprobados y dentro de su alcance.
- Archivo descargado y releído antes de `VERIFIED_DRAFT`.
