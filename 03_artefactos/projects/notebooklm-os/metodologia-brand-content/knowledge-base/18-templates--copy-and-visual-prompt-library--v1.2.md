# Prompt compiler recuperable para contenido de marca

Versión: `v1.2`
Estado: `ACTIVE_TEMPLATE_LIBRARY`
Reemplaza: `18-templates--copy-and-visual-prompt-library--v1.1`

Esta edición expresa las reglas como texto semántico normal para que NotebookLM pueda recuperarlas y citarlas. No depende de bloques de código. [METODOLOGIA]

## Campos de entrada obligatorios

Toda ejecución declara audiencia, objetivo observable, tesis de una oración, `source_ids` explícitos, claims permitidos, límites, `asset_ids` aprobados o ninguno, canal, proporción, extensión o conteo, idioma y estado de salida. El estado inicial es borrador no publicado. [METODOLOGIA]

## Compilación editorial

El editor de MetodologIA abre con una conclusión o tensión verdadera y la resuelve en el cuerpo. Orden preferido: tesis, hasta tres apoyos, evidencia o ejemplo, límite y un CTA. La voz es directa, serena, humana y metódica. La IA es aliada; propósito, criterio y aprobación permanecen en la persona. No inventa datos, citas, atribuciones o beneficios y marca `coverage_gap` cuando corresponde. [METODOLOGIA]

Por canal:

- LinkedIn: hook de una o dos líneas, situación, tesis, hasta tres apoyos, ejemplo, límite, punchline y CTA de un movimiento; sin clickbait ni hashtags genéricos.
- One-pager: decisión principal, audiencia y propósito, problema, método, evidencia, límites y siguiente paso; títulos-conclusión y bloques escaneables.
- Deck o carrusel: exactamente `N` unidades, una idea y un título-conclusión por unidad; tensión, costo, reencuadre, método, ejemplo, verificación y cierre; ninguna slide fuera del conteo.
- Formación: pregunta o síntoma, explicación, ejemplo, práctica, criterio de aceptación y reflexión.

## Prompt visual autocontenido y recuperable

Identidad visible exclusiva: MetodologIA. Estética: **Neo-Swiss Clean and Soft Explainer (Corporate Clean and Premium)**. [METODOLOGIA]

El fondo `#FFFFFF` es el sustrato funcional dominante y el espacio negativo. No es un acento cromático. El navy `#122562` funciona como ancla. La composición usa grid suizo, columnas, abundante espacio negativo y una relación clara entre texto y visual explicativo. [METODOLOGIA]

La paleta cromática exclusiva contiene exactamente seis colores: `#122562`, `#FFD700`, `#137DC5`, `#1F2833`, `#BBA0CC` y `#808080`. `#FFFFFF` y la transparencia solo funcionan como sustrato. `#FFD700` se reserva para foco, decisión o elemento activo y nunca recibe texto blanco. [METODOLOGIA]

Poppins se usa para titulares. Montserrat se usa para cuerpo. Trebuchet se usa para notas pequeñas, footnotes, popups, chips y callouts. El brief del formato declara pesos, tamaños, interlineados, fallback y disponibilidad. [METODOLOGIA]

La ilustración es vectorial flat, vibrante y funcional. Las figuras humanas no tienen rostro y aparecen solo cuando explican una acción. Se permiten formas geométricas suaves, sombras suaves, microgradientes discretos e iconografía consistente. Los elementos UI permitidos son chips, checklists, timers, cards, tabs y badges. [METODOLOGIA]

La salida usa texto grande y alto contraste. Nunca coloca texto sobre fotografías, ilustraciones complejas o fondos ruidosos. El visual explica y no decora. El estado no depende únicamente del color. [METODOLOGIA]

Negative prompt obligatorio: sin 3D; sin ciberpunk; sin fotorealismo generado; sin fondos cinematográficos; sin glassmorphism excesivo; sin neón; sin texturas densas; sin decoración vacía; sin iconos inconsistentes; sin demasiados gradientes; sin texto sobre imagen; sin marcas externas; sin colores fuera de paleta. [METODOLOGIA]

## Assets y postproducción

No se generan logos ni identidades. Se reserva una zona segura para el `asset_id` y el master aprobado se inserta en postproducción sin redibujar, recolorear, deformar o completar por IA. Los retratos se usan solo si el manifiesto declara `APPROVED` y el uso solicitado está incluido. Si falta derecho o master, el estado es `BLOCKED`. [METODOLOGIA]

## Verificación

Antes de generar se sustituyen placeholders, seleccionan fuentes, comprueban claims, contraste y derechos, elige una variante de formato y fija aceptación. Después se descargan y releen los bytes o contenido final. Una vista previa no acredita tipo, contenido, idioma ni calidad. [METODOLOGIA]
