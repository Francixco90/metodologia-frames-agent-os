# Abstract

The curriculum progresses from intentional work design to content, software, automation, agents, orchestration, and sovereign integration. Session order supports learning, but does not create authority: active canon governs definitions and each pedagogy guide governs teaching and assessment. # Progression

| Stage       | Sessions  | Capability shift                                                                                                              |
| ----------- | --------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Design work | S01–S07   | From activity and heroics to intention, presence, quality, low-friction systems, strategic time, and sustainable performance. |
| Materialize | S08–S11   | From ideas and passive documents to prototypes, multimedia, mini-apps, assistants, and reusable skills.                       |
| Orchestrate | S12–S14.2 | From isolated tools to bounded automation, agents, specialist networks, and independent verification.                         |
| Integrate   | S15–S16   | From tool use to PIVOTE, sovereign capability, reflection, and an explicit next practice.                                     |

# Session locator

- **S01:** activity → verifiable progress.
- **S02:** information consumption → retrieval, application, and transfer; no new canonical PDF is confirmed.
- **S03:** automatic behavior → designed automation plus human presence.
- **S04:** compliant output → fit-for-purpose excellence.
- **S05:** effort and rework → reusable low-friction procedures.
- **S06:** reactive calendar → strategic capacity.
- **S07:** isolated success → consistent, adaptive capacity.
- **S08:** idea → testable sketch and prototype.
- **S09:** format proliferation → directed multimodal communication.
- **S10:** attractive demo → narrow, tested mini-app.
- **S11:** generic interaction → governed assistant or skill.
- **S12:** repeated manual flow → bounded automation with readback.
- **S13:** tool delegation → agent with objective, tools, limits, evidence, and HITL.
- **S14.1:** single generalist → lead, specialists, Guardian, and handoff contracts.
- **S14.2:** agent network → minimal privilege, context sharding, observability, and failure containment.
- **S15:** fragmented practices → integrated empowerment and PIVOTE.
- **S16:** program completion → reflection, continuation, and capability stewardship.

Transversal lenses—Digital Sovereignty, Agentic Work, Intention Engineering, and Engineering of Wonder—may connect sessions but must not replace their concrete learning outcomes. [METODOLOGIA][source_ref:LEGACY-KB-11-CURRICULUM-V1]

</knowledge>

<decisions>

# Decisions

Select the smallest set of sessions that closes the learner's capability gap. Do not force chronological delivery when prerequisites are already demonstrated.

</decisions>
<assumptions>

# Assumptions

[SUPUESTO] A facilitator will adapt examples to audience and context while preserving each session's acceptance threshold.

</assumptions>
<limits>

# Limits

Completion does not certify competence. Historical model names, prices, tool comparisons, hours, or performance multipliers are not curriculum facts.

</limits>
<edge_cases>

# Edge cases

For an advanced learner, test transfer before skipping a session. For a mixed cohort, branch practice difficulty, not the canon. For S11–S16, where no dedicated v3 pedagogy guide exists, use the curriculum plus verified source material and declare the assessment design as a gap.

</edge_cases>
<acceptance>

# Acceptance

A learning path names prerequisite evidence, target capability, selected sessions, practice, transfer test, and limits. It never treats attendance, content generation, or tool usage as mastery. [PEDAGOGIA]

</acceptance>
