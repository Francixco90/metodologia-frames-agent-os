# Abstract

A hook opens a true tension, a punchline compresses an idea already supported, and a CTA proposes one proportionate movement. None may outrun the evidence. [METODOLOGIA][source_ref:LEGACY-KB-16-HOOKS-V1]

# Hooks

Choose one pattern: uncomfortable conclusion, contrast, diagnostic question, recognizable symptom, change of unit, verifiable before/after, or useful limit. Structure: **real tension + consequence or reframe**. The next line must explain, locate, or demonstrate it.

Examples: “Automating chaos only accelerates chaos.” “You do not need more prompts; you need better criteria.” “Which part of this result still depends on your memory?” [METODOLOGIA]

# Punchlines and CTAs

A punchline introduces no new promise. Useful forms: three-part rule, reframe, bounded causality, ownership, decision. Keep a visual closing line at roughly fourteen words or fewer when clarity permits; this is an editorial preference, not a universal performance rule.

A CTA uses one principal verb and matches the reader's stage: identify, rewrite, verify, design, compare, or share a bounded reflection. Do not default to “comment and share,” fake urgency, or a commercial ask in learning content.

# Channel assembly

- Social: hook → situation → thesis → up to three supports → limit → punchline → CTA.
- Carousel/deck: tension → cost → reframe → method → example → verification → close.
- Formation: question/symptom → explanation → example → practice → threshold → reflection.

</knowledge>
<evidence>

# Evidence

The patterns are brand editorial guidance. They do not guarantee reach, retention, conversion, or virality. [METODOLOGIA][source_ref:LEGACY-KB-16-HOOKS-V1]

</evidence>
<decisions>

# Decisions

Specificity outranks drama. One credible hook outranks multiple suspense lines. The CTA must never demand more trust or commitment than the evidence supports.

</decisions>
<assumptions>

# Assumptions

[SUPUESTO] The body of the piece resolves or meaningfully advances the opening tension.

</assumptions>
<limits>

# Limits

No clickbait, invented enemy, reader shaming, unsupported promise, hidden trade-off, or interchangeable motivational slogan.

</limits>
<edge_cases>

# Edge cases

If the source supports only uncertainty, use an honest question. If the subject is safety, grief, health, law, or employment, avoid playful tension. If no meaningful action is warranted, close with a decision criterion rather than a CTA.

</edge_cases>
<acceptance>

# Acceptance

Cover the brand name: the hook still describes the specific problem. Point to the evidence that satisfies it. Read the punchline aloud. Identify the CTA's single verb. Reject any line that expands the source's scope.

</acceptance>
