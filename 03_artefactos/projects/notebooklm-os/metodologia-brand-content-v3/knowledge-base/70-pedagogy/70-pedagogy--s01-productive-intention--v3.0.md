# Abstract

S01 reframes productivity as materializing an intention with observable impact and sustainable attention. AI amplifies the workflow it receives; the learner remains designer, verifier, and decision owner. [METODOLOGIA][source_ref:NFC-DRV-S01]

# Prerequisites and concepts

Prerequisite: one recent week and one recurring high-value task. Concepts: activity versus outcome versus impact; intention, attention, energy; operator versus architect; context-task-constraints-format; draft-explore-consolidate-verify; reusable workflow.

# Sequence

Audit last week's activity and outcomes. Contrast busyness with progress using the learner's case. Model a vague request, then a bounded instruction. Execute the four-stage workflow. Identify the human criterion that cannot be delegated. Convert the successful cycle into a reusable asset.

# Misconceptions

Hours or output volume equal productivity; strategy can be delegated wholesale; a lucky one-shot response is a reliable process; automation should precede a standard; model rankings remain current.

# Practice and transfer

Turn meeting notes into a one-page decision brief: state context, produce two variants, verify decisions/tasks/risks, and document the reusable workflow. Transfer to a saturated week and justify one activity to stop. [PEDAGOGIA]

</knowledge>
<evidence>

# Evidence

Expected evidence: explicit desired outcome, discard rule, designed stages, verification record, and one human decision point.

</evidence>
<decisions>

# Decisions

Teach with the learner's work rather than generic productivity tips. Compare tools only to illustrate functional fit, not enduring superiority.

</decisions>
<assumptions>

# Assumptions

[SUPUESTO] The learner can disclose a safe, non-confidential work example.

</assumptions>
<limits>

# Limits

Do not infer wellbeing, performance gains, or time savings. Historical product figures require current verification.

</limits>
<edge_cases>

# Edge cases

If every activity appears mandatory, test decision rights and dependencies. If notes contain PII, sanitize or use a synthetic case.

</edge_cases>
<acceptance>

# Acceptance

The learner distinguishes activity from progress, designs a repeatable flow, verifies the output, and explains one trade-off and one retained human criterion. [PEDAGOGIA]

</acceptance>
