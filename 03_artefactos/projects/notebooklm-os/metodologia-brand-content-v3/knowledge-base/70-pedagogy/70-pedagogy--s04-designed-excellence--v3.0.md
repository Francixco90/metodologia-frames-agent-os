# Abstract

S04 defines excellence as fit-for-purpose quality that can be specified, observed, reviewed, and improved. It rejects both minimum compliance and unbounded overproduction. [METODOLOGIA][source_ref:NFC-DRV-S04]

</abstract>

# Prerequisites and concepts

Prerequisite: one real deliverable and its audience. Concepts: mediocre/acceptable/excellent through observable criteria; audience decision; Definition of Done; reference without copying; generate-evaluate-refine-revalidate; human versus machine-readable surfaces.

# Sequence

Compare three artifacts and elicit a rubric. Define audience, decision, constraints, and DoD. Analyze a reference's function. Produce a first version. Review clarity, evidence, usefulness, visual consistency, accessibility, and portability. Correct the largest defects first. Ask what post-delivery explanation the artifact should eliminate.

# Misconceptions

Decoration equals quality; novelty equals relevance; more scope equals excellence; automated evaluation replaces accountability; a personal artifact with PII is a public golden reference.

# Practice and transfer

Improve a compliant artifact using a before/after rubric. Produce different representations only when audience needs differ, while preserving facts and provenance. [PEDAGOGIA]

</knowledge>
<evidence>

# Evidence

Expected evidence: rubric, baseline score with rationale, revised artifact, defect log, accessibility check, and acceptance decision.

</evidence>
<decisions>

# Decisions

Prioritize the three defects with greatest decision or comprehension impact. Stop when acceptance is met; do not inflate scope for spectacle.

</decisions>
<assumptions>

# Assumptions

[SUPUESTO] Audience needs and delivery constraints can be stated before revision.

</assumptions>
<limits>

# Limits

Quality criteria are contextual. No universal perfect score or ROI claim follows from a rubric.

</limits>
<edge_cases>

# Edge cases

If acceptance criteria conflict, prioritize safety/rights, then audience decision, then aesthetics. If the source artifact cannot be edited, create an accessible successor and preserve raw.

</edge_cases>
<acceptance>

# Acceptance

The learner defines a relevant rubric, corrects high-impact defects, preserves evidence and identity, and explains why the successor is better without unsupported superlatives. [PEDAGOGIA]

</acceptance>
