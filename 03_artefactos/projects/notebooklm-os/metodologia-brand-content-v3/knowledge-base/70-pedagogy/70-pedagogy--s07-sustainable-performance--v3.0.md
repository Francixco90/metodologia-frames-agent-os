# Abstract

S07 separates consistent quality from sustainable, adaptive capacity. A strong isolated result is not high performance, and consistency that collapses without one expert is not high yield. [METODOLOGIA][source_ref:LEGACY-KB-70-S07-V1-1]

</abstract>

# Prerequisites and concepts

Prerequisite: a successful outcome that currently depends on tacit knowledge. Concepts: isolated success; consistent quality; sustainable capacity; learning dip; SOP; roles, exceptions, quality and capacity indicators; adaptation; escalation; industry standards as inputs, not automatic authority.

# Sequence

Contrast isolated, consistent, and sustainable results. Elicit tacit knowledge through observation. Convert it to a procedure with owner, criteria, and exceptions. Compare with relevant standards. Run with another actor. Audit quality, adaptation, risk, and dependency. Create a successor that reduces hero dependence.

# Misconceptions

One peak proves performance; immediate yield should dominate learning; volume equals value; standards are recipes; AI permits unlimited workload; unsupported neurochemical language explains behavior.

# Practice and transfer

Co-create an SOP, test it with a second operator, introduce one controlled variation, and evaluate whether quality survives without the expert's rescue. [PEDAGOGIA]

</knowledge>
<evidence>

# Evidence

Expected evidence: baseline dependency, SOP, role map, quality/capacity indicators, exception result, and adaptation decision.

</evidence>
<decisions>

# Decisions

Accept a temporary learning dip when it builds verified capacity. Measure output quality and system sustainability separately.

</decisions>
<assumptions>

# Assumptions

[SUPUESTO] A safe second-operator or simulation test is available.

</assumptions>
<limits>

# Limits

No biological, clinical, or universal productivity claim is implied. An SOP alone does not create resilience if authority and resources remain centralized.

</limits>
<edge_cases>

# Edge cases

If expert intervention remains necessary, make the escalation explicit instead of hiding it. If standardization harms legitimate variation, define controlled ranges rather than one rigid script.

</edge_cases>
<acceptance>

# Acceptance

The learner distinguishes current output from installed capacity, demonstrates consistent quality under one variation, and reduces or explicitly governs expert dependency. [PEDAGOGIA]

</acceptance>
