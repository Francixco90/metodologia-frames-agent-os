# Abstract

S02 treats learning as a cycle of mapping a domain, investigating, triangulating, consolidating, retrieving without notes, applying in a new context, receiving feedback, and updating the model. Fluent AI output is neither truth nor competence. [METODOLOGIA][source_ref:LEGACY-KB-70-S02-V1]

</abstract>

# Prerequisites and concepts

Prerequisite: a concrete capability and a baseline self-example. A Body of Knowledge maps the domain; a Capability Model defines progressive performance. Multiple AI answers support exploration, not source triangulation. A notebook is only as reliable as its authority, selection, and gaps.

# Sequence

Define capability and baseline. Build domain map and glossary. Collect primary and secondary sources. Record contradictions. Consolidate a small source set. Explain without notes. Solve a new case. Compare result with criteria and update what must be learned or unlearned.

# Misconceptions

Consumption equals mastery; model agreement proves truth; hundreds of sources improve retrieval; generated podcasts replace practice; suggested hours guarantee competence; onboarding and S02 are automatically equivalent.

# Practice and transfer

Create a research blueprint, select a bounded source set, surface one contradiction, perform closed-note reconstruction, and apply the concept to a new case. [PEDAGOGIA]

</knowledge>
<evidence>

# Evidence

Expected evidence: source rationale, contradiction record, retrieval attempt, applied artifact, feedback, and successor model.

</evidence>
<decisions>

# Decisions

Teach source authority before notebook scale. Use AI as tutor, critic, and simulator under cited sources—not as sole authority.

</decisions>
<assumptions>

# Assumptions

[SUPUESTO] The learner can access at least one authoritative source and a safe practice context.

</assumptions>
<limits>

# Limits

No direct new canonical S02 PDF is confirmed; onboarding alignment remains a curriculum gap. No retention or neuroscience claim is made without specialist evidence.

</limits>
<edge_cases>

# Edge cases

When sources conflict, retain both and explain authority/date/scope. When the learner cannot practice in production, use a realistic simulation and label it.

</edge_cases>
<acceptance>

# Acceptance

The learner justifies sources, retrieves without notes, applies to a different case, incorporates feedback, and distinguishes confidence from evidence. [PEDAGOGIA]

</acceptance>
