# Abstract

Understanding is demonstrated through retrieval, application, explanation, and transfer to a new situation—not through attendance, fluent repetition, or an attractive generated artifact. This matrix defines observable evidence and minimum thresholds for S01–S10. [PEDAGOGIA][source_ref:LEGACY-KB-70-MATRIX-V1]

# Assessment protocol

1. Elicit the learner's current model before instruction.
2. Teach with one worked example and one contrasted non-example.
3. Remove notes and request explanation or reconstruction.
4. Apply the principle to a materially different case.
5. Inspect the produced evidence against the threshold.
6. Give specific feedback; retry only the failed dimension.

| Session | Transfer prompt                                                    | Observable evidence                                         | Minimum threshold                                                   |
| ------- | ------------------------------------------------------------------ | ----------------------------------------------------------- | ------------------------------------------------------------------- |
| S01     | Redesign a saturated week for verifiable progress.                 | priorities, discard rule, focus blocks, outcome             | distinguishes activity from progress and justifies one trade-off    |
| S02     | Learn a new capability without confusing consumption with mastery. | acquisition, retrieval, application, feedback, update       | includes closed-note retrieval and a new-context task               |
| S03     | Find an automation that requires human presence first.             | trigger-response-consequence map, intervention rule         | identifies risk, human decision, and improvement signal             |
| S04     | Elevate a merely compliant deliverable.                            | audience rubric, revision, before/after rationale           | adds relevant value, not ornament or excess scope                   |
| S05     | Remove harmful friction while preserving protective friction.      | current flow, friction classes, redesign, guardrails        | reduces waste without removing learning, control, or accountability |
| S06     | Convert a reactive day into strategic capacity.                    | outcome, decisions, blocks, dependencies, closeout          | funds focus, review, learning, and contingency                      |
| S07     | Remove hero dependence from a successful process.                  | SOP, roles, quality, capacity, adaptation, escalation       | separates present result from sustainable capability                |
| S08     | Choose the smallest representation that can change a decision.     | hypothesis, prototype, user test, stop/iterate rule         | test can disconfirm the hypothesis                                  |
| S09     | Translate one thesis into two media.                               | two distinct briefs, source sets, media grammar, acceptance | preserves thesis while adapting interaction and accessibility       |
| S10     | Prove a mini-app is more than a polished demo.                     | user, decision, states, data, happy/error/recovery test     | completes critical flow and discloses simulated versus real data    |

# Evidence

The thresholds are instructional design decisions synthesized from the formation corpus. They are not psychometric validation or certification standards. [PEDAGOGIA][source_ref:LEGACY-KB-70-MATRIX-V1]

</evidence>
<decisions>

# Decisions

Assess the targeted capability, not tool fluency. Require a different context for transfer. Keep feedback specific to the failed criterion.

</decisions>
<assumptions>

# Assumptions

[SUPUESTO] Learners can access a realistic but safe practice case. [SUPUESTO] Facilitators can observe the process or its artifacts.

</assumptions>
<limits>

# Limits

Passing one task does not prove broad mastery, long-term retention, or workplace impact. Cohort comparison requires a separately designed assessment.

</limits>
<edge_cases>

# Edge cases

If prior expertise is high, use transfer first. If accessibility affects production mode, accept equivalent evidence. If group work obscures individual understanding, add a short individual reconstruction.

</edge_cases>
<acceptance>

# Acceptance

Every learning claim identifies the task, independent evidence, threshold, assessor, feedback, and remaining gap. Attendance and self-report may complement but never replace observable performance.

</acceptance>
