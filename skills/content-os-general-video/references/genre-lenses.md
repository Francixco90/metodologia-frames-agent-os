# Genre Lenses — Companion Flow

For `flow: companion`, before the first plan, read `content-os-creative`
story-spine + house-style + the nearest genre lens + the full capability-menu.
The ceiling treatment is designed from these, not recalled.

## Borrowed workflows

When the piece resembles a shipped workflow, borrow its genre references as
**examples** — story shape and taste, not its private scripts, pipeline state,
or directory contract. The generic build remains owned by this skill.

| Resembles                          | Borrow from                                                     |
| ---------------------------------- | --------------------------------------------------------------- |
| Explainer, talking-head + captions | `content-os-faceless-explainer`, `content-os-embedded-captions` |
| Code-change explainer              | `content-os-pr-to-video`                                        |
| Site tour / launch                 | `content-os-product-launch-video`                               |
| Short motion-first unit            | `content-os-motion-graphics`                                    |
| Navigable deck                     | `content-os-slideshow`                                          |

## Story spine (narrated arcs)

For narrated pieces, read `content-os-creative` story-spine. The spine defines
the arc: hook → tension → turn → resolution. Each scene serves the spine; a
scene that doesn't is cut.

## Beat direction (rhythm)

For rhythm, read `content-os-creative` beat-direction. The beat grid drives
duration: music beats, VO cadence, visual punctuation. Real voice duration
overrides estimates at assembly.

## Composition patterns (structure)

For structure, read `content-os-core` composition-patterns. Single-scene vs
multi-scene, sub-compositions for three or more hard cuts or any reused scene.

## The ceiling treatment

For `flow: companion`, the first plan is the ceiling treatment:

1. **Story arc** — borrow the nearest genre lens.
2. **Design spec** — brand tokens, font pairing, focal/edge/supporting/background.
3. **Each scene's motion treatment** — cited by name from `content-os-animation`
   blueprints/rules indexes, never invented.
4. **Transitions** — named, serving the arc.
5. **Audio identity** — music and sound marks, or deliberate silence.
6. **User's material placed** — not defaulted.
7. **Designed open and close** — not defaulted.

Say what each layer adds in one line; flag the expensive ones (render time,
sign-in, billing) as you name them. The user trims a treatment down; they should
never have to assemble one approval by approval.

## The ceiling belongs to the concept, not the toolbox

Every layer must serve the brief's message. A treatment that would dress any
video the same way is decoration. Craft rises to the ceiling; content never
grows past what was asked (scope exact).
