# Story design — faceless explainer

Estructura narrativa para explainer faceless. El video viene de **narrative
design**, no del orden de párrafos del input. Reordena, mergea, omite, comprime.

## Estructuras (elige una por topic)

### Concept

Topic abstracto → descomponer en partes. Hook con analogía → definir → ejemplos →
contraste → recap. Fuerte para "qué es X", "cómo funciona X".

### How-to

Proceso secuencial. Hook con outcome → prerequisites → pasos en orden → pitfall
→ resultado. Fuerte para "cómo hacer X", "guía de X".

### Listicle

Lista numerada. Hook con tesis → items (3-7) cada uno con valor → tesis recap.
Fuerte para "N razones", "N formas", "N errores".

### Story

Narrativa con personaje/arco. Hook con stakes → setup → conflicto → resolución →
lección. Fuerte para case studies, ejemplos narrativos.

## Hook

Hook language: 1-2 frames que ganan atención. No clickbait; promesa clara del
valor. Tipos: pregunta, contraintuitivo, stat, analogía, stakes.

## Value-before-evidence

Cada beat entrega valor antes de justificarlo. No acumules evidence sin decir
por qué importa. El viewer debe saber qué gana entendiendo cada beat.

## Storyboard as proposal

El storyboard es una propuesta (review loop), no un dictado. Presenta el plan,
pide approve-or-change. Step 3 es user-gated.

## VO mode

- **Verbatim** — user dio script, mantén wording. Solo ajusta timing.
- **Restructured** — reshape para narrative design. Reordena, comprime.
- **Silent** — no narration. `music: none` + no SCRIPT. Visual-driven.

VO_MODE viene del brief (router lo pide si user dio script). Si brief falta, ask
once en Step 1.

## Duración

Especializados fuertes 30-90s. >180s → router rerutea a `content-os-general-video`.
Length nunca overridea la estructura; estructura decide length.

## Delegación

Story doctrine (hook, value-before-evidence, proposal shape) →
`content-os-creative` story-spine. Este doc es el delta faceless (estructuras
explainer + VO mode faceless). No dupliques motion rules (→
`content-os-animation`), no dupliques brand (→ `content-os-creative`).
