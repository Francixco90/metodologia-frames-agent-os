# Contribución

## Flujo

1. Selecciona un paquete del DAG.
2. Confirma su dependencia y allowlist.
3. Implementa cambios pequeños y deterministas.
4. Ejecuta los checks del paquete.
5. Registra handoff y hashes de outputs.
6. Solicita revisión a un verifier distinto.

No se aceptan dependencias flotantes, assets sin licencia, claims sin fuente, red durante render, mutaciones live ni publicación desde CI.
